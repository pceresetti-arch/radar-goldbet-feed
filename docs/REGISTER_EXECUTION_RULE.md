# Radar Unico - Regola registrazione giocate

Attiva dal 2026-09-04.

Ogni conferma esplicita dell'utente come "giocato", "messo", "presa", "registra" o "salva giocata" deve generare subito una voce nel registro centrale persistente.

Campi da salvare, quando disponibili: data, partita, selezione, mercato, bookmaker, quota presa, stake, stato PIAZZATA, ritorno potenziale, utile netto potenziale e classificazione Radar pre-bet.

Se viene fornito un ticket o screenshot, i dati del ticket hanno priorita per quota, stake, mercato, orario e ritorno potenziale.

Prima di fornire un riepilogo giornaliero, verificare il registro persistente e le conferme recenti per evitare omissioni.
